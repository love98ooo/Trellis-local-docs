Read `.trellis/workflow.md` in the current worktree. It is the single source for phases, authorization, Agent dispatch and acceptance. Platform Skills and hooks load and route to it.

To change fork defaults, edit the [workflow template source](https://github.com/love98ooo/Trellis/blob/main/packages/cli/src/templates/trellis/workflow.md) and verify init/update using the same pinned CLI build. Specs, tasks and journals stay local to the current worktree.
